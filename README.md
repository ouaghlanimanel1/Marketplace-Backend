# Marketplace Backend

## Overview
A RESTful backend for a marketplace web application built with Java and Spring Boot.

## Features
- REST API architecture for seamless client interaction
- User, product, and order management
- Data persistence using Spring Data MongoDB
- Integration with the Angular frontend

## Technologies
- Java
- Spring Boot
- Maven
- Spring Data MongoDB
- REST APIs

## Getting Started

### Prerequisites
- JDK 17+ 
- Maven
- MongoDB server running locally or via MongoDB Atlas
